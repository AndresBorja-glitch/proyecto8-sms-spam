# Notebook

`proyecto_sms_spam_corte3.ipynb` contiene el proyecto completo en un solo notebook: carga y depuración de datos, partición, línea base, modelo del Corte 2, profundización (n-gramas de caracteres, calibración, umbral por costo, comparación con embeddings), evaluación final en test, robustez, función de inferencia y demo.

Se ejecuta en Google Colab con «Ejecutar todo»; descarga el dataset desde UCI.
